# 苔萍防线 Demo

《苔萍防线》是一款把打字输入、塔防防守和词汇构筑结合在一起的独立游戏 Demo。

玩家需要在战斗中输入场上生成的词汇，驱动英雄和防御塔攻击敌人、升级、积攒怒气或恢复生命。打出的词不一定要立刻释放，也可以冻结进储词框，等待合适时机一次性激发，触发“五芒贯日”和不同 Combo。

## 下载与运行

请在本仓库的 **Releases** 页面下载最新版本的 Windows 试玩包。

运行方式：

1. 下载 `TaiPingDefense_Demo_Windows.zip`
2. 解压压缩包
3. 运行其中的 `.exe` 文件
4. 如遇 Windows 安全提示，请点击“更多信息” -> “仍要运行”

推荐环境：

- Windows 10 / Windows 11
- 1920x1080 分辨率
- 键盘输入

## 核心玩法

- 场上会自动生成英文词汇
- 输入对应词汇后，英雄或防御塔会触发行动
- 防御塔可以自动攻击，输入词汇可带来升级、怒气、回血等效果
- 英雄需要通过输入词汇主动攻击
- 匹配成功的词可以立刻激发，也可以冻结进储词框
- 存够五个词后，可以触发“五芒贯日”
- 不同词长和组合会形成不同 Combo，例如“排山倒海”“连珠星”等，带来倍率加成

## 操作说明

- 直接使用键盘输入场上显示的词汇
- 输入正确后，对应词汇会被匹配
- 匹配成功后，可根据游戏内提示选择立即激发或冻结存词
- 存够五个词后，可触发五芒贯日
- 游戏内部分界面可使用鼠标点击确认或选择

## 关于游戏

游戏发生在浮萍王国与苔藓部族的水生童话战争中。己方英雄和防御塔以水生植物为原型，敌人则来自苔藓联合部族。

这个 Demo 的目标是验证一个核心想法：

> 打字不只是输入，也可以成为一种可积攒、可选择时机、可爆发的塔防资源。
